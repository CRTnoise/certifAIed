# CertifAIed

An interactive AI course, in English and French, in a single static page: 16 units from "what is learning" to transformers, RAG, LangChain agents, quantization and evaluation, with live labs, auto-checked missions, pen-and-paper practice and interview questions.

## Run it
Open `index.html` in a browser, or visit the GitHub Pages URL.

## On Android
Open the site in Chrome → menu (⋮) → **Add to Home screen** / **Install app**. After the first visit it also works offline.

## Privacy
No accounts, no analytics, no server. Quiz and mission progress is stored only in your own browser (localStorage), and can be backed up as a code from the footer. The only third-party request is Google Fonts.

Courtesy of CRTnoise.

## Updating
Edit the files, then bump `VERSION` in `sw.js` (and the `?v=` in `index.html`) so phones pick up the new version.
